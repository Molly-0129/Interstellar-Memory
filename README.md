# ✦ Interstellar Memory · 星间记忆

用于 SillyTavern 超长叙事对话的长期记忆扩展。

**当前版本：0.2.0 测试版。** 两套内置提示词使用用户提供的原文，保留其转义符、缩进和措辞。模型负责完整总结与分卷浓缩，程序负责格式检查、保存检查点和楼层隐藏。尚待实际酒馆与 Gemini 联调。

## 安装或更新

在酒馆「扩展 → 安装扩展」中粘贴：

https://github.com/Molly-0129/Interstellar-Memory

已安装的用户请在扩展管理中检查更新，更新后刷新页面。安装不需要运行 npm 或另装服务器插件。

0.1.0 的旧内置默认提示词会自动切换到新默认值。自行修改过的提示词会保留；如需改用本次提供的版本，在「星间记忆设置 → 独立总结提示词」点击「恢复两套默认提示词」，然后保存。

## 使用

打开单角色聊天，点击输入区域的 **✦ → 立刻大总结**。插件使用酒馆当前模型连接，在后台发送独立请求。

- 普通总结由模型生成完整的 <星间大总结> 标签块，内部为 YAML。
- 分卷总结由模型生成完整的 <星间卷宗> 标签块，内部为 YAML。
- 程序按模型返回的原文保存到聊天消息，包含原有空白和 YAML 格式。
- 不进行程序内容合并、去重、重排、改写、浓缩或补入旧事件。
- 不向请求追加通用写作提示词、JSON Schema 或增量输出协议。
- 旧总结、相关剧情与锁定内容作为材料提供给模型，由模型整合和取舍。

提示词原文可查看 [普通大总结](docs/ordinary-prompt.txt) 和 [分卷大总结](docs/archive-prompt.txt)。

## 保存与隐藏

模型结果通过标签、YAML 语法及必要字段检查后，先保存新总结并从服务器读回核验，再隐藏被接替的旧总结和已覆盖正文。原聊天仍然保留。

总结前最近四条未隐藏剧情暂留，通常为两轮问答。总结后再产生四条有效剧情消息，隐藏先前暂留的四条。当前有效总结始终受到保护。

每次整理前创建独立的完整聊天检查点。生成失败、格式错误、保存失败或来源变化时，不提前隐藏原文。

## 默认设置

| 设置 | 默认值 |
| --- | --- |
| 自动普通大总结 | 关闭 |
| 自动楼层条件 | 未隐藏剧情 ≥ 200 条 |
| 自动 Token 条件 | 同一批未隐藏剧情 ≥ 256,000 Token |
| 两个自动条件 | AND，同时满足 |
| 分卷解锁 | 当前有效总结原文 ≥ 64,000 Token |
| 总结最大输出 | 16,384 Token，可调整 |
| 模型总窗口 | 使用酒馆设置，可手动填写 |

设置只作用于当前聊天。计数使用酒馆分词器。请求超出窗口时停止，不自动截断材料。

分卷解锁后需手动点击，只整理已有总结；新增正文可先执行普通总结。分卷结果不会因为没有低于某个程序容量目标而被再次改写或自动重试。

一层是一条实际剧情消息；续写、重生成或切换同一楼层的备选回复不额外增加层数。

## 材料与界面

设置支持编辑两套独立提示词，并补充：
- 用户锁定的不压缩内容；
- 最新活跃伏笔清单；
- 独立保存的剧情档案；
- 整理所需的角色与世界设定。

这些材料原样保存在设置中，每次作为输入提供给模型。是否被正确继承由模型负责；程序不把它们追加或合并进模型的总结正文。正文中的剧情档案随正文参与整理，角色卡基础描述、性格与场景作为参考材料。

操作面板继承酒馆 UI。消息美化由外部窗口完成，插件不提供天文皮肤、折叠美化或额外 details 包装；聊天消息中直接保留模型输出标签。

## 恢复

- 「恢复中断操作」恢复本次整理之前的记忆与隐藏标志。
- 「撤销上次整理」恢复上次整理前的状态，保留后来新增的消息。
- 「打开整理前检查点」打开完整原文的独立检查点聊天。
- 「导出记忆与操作记录」下载 JSON 备份，其中包含原始总结文本。

已总结的正文被编辑、删除或切换备选回复时，插件暂停后续隐藏；请使用整理前检查点建立恢复分支。修改当前总结正文也会触发一致性保护。

检查点以「聊天名 - INTERSTELLAR 操作编号」保存，包含完整聊天；清理之前请确认不再需要恢复。

## 当前边界

首版支持单角色聊天，群聊尚未开放。其他扩展的存储联动未接入；世界书和向量检索等功能可能独立召回旧信息。并行标签页编辑同一聊天也可能产生冲突。

格式检查不能证明总结事实完整。新版本完全采用模型输出，不通过程序重新合并旧历史；请在测试时核对模型是否继承了重要事实、秘密知情范围、锁定内容和未决伏笔。
