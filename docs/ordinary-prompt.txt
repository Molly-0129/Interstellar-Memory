# ✦ 星间 · INTERSTELLAR

## 普通大总结

<任务目标>\
回顾并整合已有故事记录，生成截至当前时刻的长期叙事记忆。

本次任务仅进行事件回顾、历史更新与当前状态整理，不继续剧情、不扮演角色、不补写未发生的事件。

总结应当准确、完整、凝练，能够为后续叙事提供可靠的历史依据。\
\</任务目标>

### 一、信息整理

1. 综合可获取的既有大总结、剧情正文、剧情档案、活跃伏笔及相关角色与世界设定。
2. 如果存在旧总结，以其为历史基础，将后续新增事件整合进去，形成更新后的完整总结。避免重复记录同一事件。
3. 保持事件的时间顺序、因果关系及人物行为逻辑。明确日期只有在存在可靠依据时才记录，不凭空推算。
4. 区分客观事实、角色认知、秘密、传闻与推测。尤其注意不同人物各自知道什么、不知道什么。
5. 对相互矛盾的记录，先检查是否源于故事发展和状态变化；无法判断时标记待核实，不擅自补造解释。

### 二、主要事件时间线

按故事内部的时间顺序记录具有叙事意义的事件，包含：

- 时间、地点、参与人物。
- 事件的重要经过、选择、对话或承诺。
- 事件的原因、结果及持续影响。
- 重要信息的获得与传播、关系变化、物品流转、环境及社会状态变化。

对相关联的事件可以适度合并，但不得丢失独立的重要事实。日常事件可以概括，关键情节需保留必要细节。

本模式以维护完整历史记忆为目标，不主动将较早的历史浓缩为分卷概述。

### 三、当前世界状态

记录截至故事最新时刻的实际状态，而非罗列历史上曾经存在的状态。

**重要人物：** 姓名、身份、当前位置、身体与生活处境、主要目标、正在进行的事务及其他持续有效的重要信息。

**人物关系：** 重要人物之间的情感、社会或利益关系，当前互动状态、关系变化、已成立的承诺及尚未解决的分歧。区分单方面感受与双方确认的关系事实。

**信息与秘密：** 具有持续意义的重要秘密、情报、误解及其真实性、知情范围。

**重要物品与资源：** 关键物品、文件、财产与资源的当前归属、存放位置、使用或损毁状态。保留必要的转移经过。

**地点与环境：** 当前场景、重要人物所在地，以及仍会影响后续事件的地点、组织或社会环境变化。

**未决事务：** 尚未完成的行动、承诺、冲突、风险与待处理事项。

### 四、重要细节

自主识别并保存具有长期叙事价值、不能因时间推移而轻易遗失的细节，包括重要原话、誓言、身份事实、特殊物品、重大经历、持续有效的世界规则及关键因果关系。

已有的重要细节应当继承、去重与更新。

长期保存不代表状态永远不变。如果承诺已履行、物品被损毁、秘密已公开，应保留历史事实，同时更新其当前效力。

用户明确要求长期保留的细节必须继续保存。

### 五、与现有记忆模块协作

- 剧情档案用于核对各轮事件和状态变化。
- 活跃伏笔用于识别尚未解决的重要线索；不得因为某条线索暂时没有新进展，就将其认定为已经完成。
- 大总结负责整合长期历史和当前状态，不必逐字重复整份活跃伏笔清单。

已解决的伏笔可作为历史事件保留必要结果；仍未解决的伏笔应保持与最新活跃伏笔记录一致。

### 六、输出要求

只输出一个 `<星间大总结>` 标签块，内部使用 YAML 结构，不使用 Markdown 代码围栏，不添加解释、评价或其他文字。

根据实际信息量增减列表项目。没有相关内容时使用空列表 `[]`，未知但必要的信息注明「未知」。不要为了填满模板而虚构事实。

### 七、最终检查

确认事件顺序正确、重要因果完整、人物状态与最新剧情一致，秘密没有错误传播，物品归属没有混淆，未解决的伏笔没有被错误回收。

总结只记录已经成立的信息，保留必要的不确定性。
