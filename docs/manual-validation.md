# 0.2.0 实机验收

1. 更新扩展并刷新页面。在「独立总结提示词」确认两套提示词为本次用户版本；有自定义旧提示词时，可点击恢复默认并保存。
2. 用一个测试单聊准备至少三轮问答，点击普通大总结。
3. 确认最新一条原始消息为 <星间大总结> 内的 YAML，程序没有增加 details 包装或改写模型结果。
4. 核对完整历史、当前世界状态、重要细节、秘密知情范围和活跃伏笔是否被模型正确继承。
5. 打开实际模型请求检查：旧总结原文和新增材料在场，没有旧 JSON 增量协议或额外共同提示词。
6. 检查旧正文暂留四层；新增三层仍保留，第四层完成后隐藏。当前总结仍提供给模型。
7. 再做普通总结，确认旧总结隐藏但仍可查看原文，最新消息完整采用模型新结果。
8. 临时降低分卷解锁阈值，执行分卷。确认输出 <星间卷宗>，归档取舍全部由模型完成，程序不重排或再压缩。
9. 临时降低自动普通总结的两个阈值，验证仅满足一个时不触发，AND 达标后在 AI 回复结束时触发。
10. 模拟取消、网络失败或错误 YAML，确认不会提前隐藏原上下文，恢复入口可用。
11. 已总结来源被编辑或切换备选回复时，确认停止延迟隐藏并提示使用检查点。
12. 核对外部消息美化匹配两个新标签，实际保存给模型的原始消息不受视觉美化影响。

测试内容、模型与酒馆版本请随结果记录。自动化测试覆盖格式、保存与隐藏流程，不替代实际模型内容检查。
