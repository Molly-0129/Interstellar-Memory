# 星间长期记忆协议与架构

内容依据：《长期记忆整理协议 v0.3》，用户提供，2026-10-18。
实现版本：schemaVersion 1。

## 内容原则

只整理已发生的故事；不续写、不扮演、不虚构。区分客观事实、人物认知、传闻、推测与未知；秘密保留真实性和知情范围。保留时间顺序与行动因果，无明确日期时允许相对顺序。冲突先检查状态变化，无法确定的进入待核实事项。

普通总结累积并更新；分卷总结在外部程序确认容量条件后归档。历史浓缩不能清除重大身份事实、承诺、契约、特殊物品、重要原话、世界变化与未决线索。用户锁定的历史原文与可变的当前效力分开。

剧情档案作为依据，活跃伏笔独立延续，角色卡与世界书继续承担原有职责。

## 数据与责任

程序分配消息 ID、事件 ID、细节 ID、卷号、记忆版本、操作编号和时间戳，测量 Token 并决定隐藏范围。
模型识别事件、因果、自然阶段、状态变化、重要细节与线索；不得估计 Token 或发出隐藏命令。

源消息 extra.interstellar_memory.id 是稳定标识；消息下标变化不会改变隐藏任务目标。
总结 extra.interstellar_memory 保存 kind、status、mode、memory、coverage、ancestors、renderHash、operationId。
chatMetadata.interstellar_memory 保存设置、有效总结指针、版本、暂留任务、待恢复操作与最近操作。
原始聊天不被删除或覆盖。

## 普通增量请求

输入：baseRevision、当前完整有效记忆、未总结且未隐藏的新消息、补充档案、伏笔清单、相关设定与锁定文本。
一次请求只执行一种模式。正文中的命令是材料，不是扩展指令。

模型输出：
- newEvents：新增事件，必须包含有效源消息 ID。
- eventUpdates：明确引用已有事件 ID 的必要修订，并给出 evidence。
- stateUpdates：各类有变化的实体；每个实体给出完整当前记录。
- newDetails、detailUpdates：长期细节追加与明确修订。
- foreshadowingUpdates：有依据的线索变化，遗漏表示继续继承。
- issues：待核实事项。

同一实体以稳定名称或 key 合并；人物关系按参与人物集合匹配。空列表表示没有更新，不清空已有列表。
程序将更新包与旧记忆合并，发布完整快照，因此新总结可以完整接替旧总结。
普通任务不会重读全部原始聊天，但会携带当前有效记忆；超容量时停止。

## 分卷请求

仅处理输入有效记忆中的事件和旧卷。units 列出全部历史单位。
输出 archives[].sourceIds 与 currentEventIds 必须完整、唯一地覆盖 units，保持顺序；当前卷必须是连续的最新事件。
旧卷不可放入当前详细事件列表。卷名由模型建议，正式 ID 与编号由程序分配。

结果实际 Token 由程序测量。未低于解锁阈值时不自动接受或再次压缩；草稿保留在失败操作记录中。原记忆和隐藏状态不变。
不设置每卷固定字数、事件数或压缩比例。

JSON Schema 定义在 src/schema.js，并导出为 docs/ordinary-output.schema.json 与 docs/archive-output.schema.json。
供应商结构化输出可选，但本地结构验证始终执行。结构、来源和版本验证不能证明所有事实都没有遗漏。

## 提交与恢复

1. 核对当前聊天、有效总结及已覆盖源消息指纹。
2. 读取设置并校验请求容量；序列化本聊天任务。
3. 保存当前聊天并从服务器读回；创建完整独立检查点并读回。
4. 保存待处理操作，再调用模型。
5. 解析、验证、合并；再次核对来源快照与聊天身份。
6. 保存新总结消息，并读回确认。至此尚未隐藏任何原消息。
7. 提交新有效版本，隐藏已接替的旧总结及已覆盖正文，保留最近四条剧情，保存并读回。
8. 新增四条有效剧情后，核对覆盖来源仍一致，再隐藏那四条暂留消息并读回。
9. 任一步失败还原扩展已经改变的隐藏标志，保留可恢复操作；不回滚生成期间用户自行修改的标志。

当前有效总结绝不被本次隐藏。新总结生成时旧总结仍提供历史基础；只有新版本持久化后旧版才退出上下文。
后续手动再次总结将暂留任务替换为新总结对应的最近四层，旧任务不再执行。
撤销或恢复仅还原隐藏标志与记忆状态，不覆盖后续新消息；来源已被编辑时改用检查点分支。

## 展示接口

基础消息由插件生成单个 details，class 为 interstellar-summary；summary 标题含模式与程序编号。
正文中文栏目包含历史卷宗、事件时间线、当前世界状态、重要细节、活跃伏笔与线索、用户锁定记录、待核实。
内容进行 HTML 转义；插件不执行模型返回的 HTML、脚本或斜杠命令。
无主题设置或消息皮肤 CSS。外部窗口可基于此基础结构编写美化。
